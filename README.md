Entry for the make.fun bounty [The Funniest Auto-Reply an AI Ever Sent](https://make.fun/bounty/u-kiencx-the-funniest-auto-reply-an-ai-ever-sent-fda7f526).

The program writes one original out-of-office auto-reply, a single
line, as if the AI agent itself were stepping away for a day its
human finally approved.

## Run

```sh
python3 main.py
```

This writes the one-line entry to `/output/entry.txt`
(UTF-8, 1-159 characters, deterministic, offline, no randomness,
no wall-clock).
